JavaScript

JavaScript is the programming language that runs inside the web browser. It makes web pages interactive, responding to clicks, updating content, and sending requests without reloading the page.

JavaScript and the web

JavaScript is a core part of modern web development. Together with HTML and CSS it forms the front end that users see and interact with in the browser.

Beyond the browser

JavaScript can also run on servers, letting the same language power both the front end and the backend. Server side code often talks to databases to store and retrieve data.
