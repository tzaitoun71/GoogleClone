Five ideas worth keeping

If you remember nothing else from the codebase, remember these.

symmetry

One tokenizer, both sides

Pages and queries run through the same tokenize(). Matching only works because "Python!" and "python" collapse to the same string. Two tokenizers would be two bugs.

the math does it for you

No stopword list

IDF is log(N/df). A word in all 40 docs scores log(1) = 0 and contributes nothing. "the" silences itself — you never wrote a list.

saturation

The 20th mention is worthless

BM25 caps how much repetition helps and only partly divides by length. That's the fix for the 53-token stub outranking the real Einstein page.

two signals

Authority is a tiebreaker

PageRank doesn't know what you typed. Weight it past ~0.4 and the homepage wins every search — try it in the lab above.

asymmetry

Slow once, fast forever

Crawl, parse, index, PageRank: minutes, at startup. A request only tokenizes, looks up postings, and scores a handful of candidates.

Check yourself

Answer before you open it. Recall beats re-reading — this is the part that makes it stick.
