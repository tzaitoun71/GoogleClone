Databases

A database is an organized system for storing data so that it can be found and updated efficiently. Almost every serious application relies on a database to keep its information safe and structured.

Querying data

Programs read and write data using queries. A query describes what records are wanted, and the database returns just those records, even from very large collections of data.

Databases in practice

Databases sit behind most software. A web development project stores its users and content in one, and a data science workflow often begins by pulling records out of one.
